# PR24 复审补齐说明（workbench 工具）

本页记录隔离工作树 `v1-8-workbench-review/srtp_Voice`（HEAD `49bbb6d9`）上针对 5 条 P2 复审的补齐内容与限制。

## 配置指纹的含义与边界

* `CONFIG_KEYS` 现在覆盖实际影响流水线延迟的非敏感设置，包括 VAD（`pre_roll_ms`、`vad_calibration_ms`、`vad_noise_multiplier`、`vad_release_ratio`、`vad_threshold`、`min_speech_ms`）、ASR（`asr_device`、`asr_compute_type`、`asr_cpu_threads`、`asr_beam_size`、`asr_language`、`asr_vad_filter`、`asr_min_silence_ms`、`asr_condition_on_previous_text`）、LLM（`llm_temperature`、`llm_context_tokens`、`llm_timeout_seconds`、`llm_fallback_to_mock`、`llm_max_tokens`）、SER（`ser_model`、`ser_device`、`ser_language`、`ser_fallback_to_heuristic`）、流式队列与分句、TTS（含 Piper 模型/配置/输入格式/超时/额外参数/espeak 数据路径的**安全投影**）以及情绪平滑参数。
* 所有取值都经过既有 `_safe_config_value` 投影：路径只保留安全文件名，URL、绝对路径、非安全 token 一律变成 `<redacted>`；`.env` 原文、私有目录、URL 与额外参数原文不会进入可分享文档。
* `config_fingerprint` **只对完整且取值已知的配置**成立：任一键缺失、取值为 `None`（除源码确实可选的 `ser_model` / `tts_piper_config` / `tts_piper_extra_args` / `tts_piper_espeak_data`）、被投影为 `<redacted>` 或为非有限数值时，指纹输出 `None`（未知），不会用当前机器缺省值补出“录制时配置”。
* 来源文本同样严格校验：`git_head` 仅接受 40/64 位十六进制，`config_fingerprint` 仅接受 64 位十六进制，`python` 仅接受 ASCII 主次版本（可选 patch 与标准 `a/b/rc` 预发行，如 `3.11`、`3.12.10`、`3.14.0rc1`），`os` 仅接受 `Windows` / `Linux` / `Darwin`。全部使用 **fullmatch**，因此尾随换行或夹带文本（例如 `3.12<任意文本>`）都会被拒；被拒的值统一变成未知，错误信息不回显原值。
* **指纹不是等价性证明**：它只说明两次运行导出的配置视图一致，不代表模型权重、设备、录音质量、说话人或听感一致。

## 旧快照兼容

扩展 `CONFIG_KEYS` 之前生成的 snapshot 缺少新增键：其配置视为**不完整**，指纹记为未知，与当前基线**不可比**。不要手工修改旧文件补写来源或指纹；如需比较，请用相同版本重新录制。

## 空 turn 与真实运行证据

所有 turn 清洗后若没有任何一条保留有效 `latencies_ms`，产物不再声称 per-turn 计时证据：不导出这些记录（声明计数必须与记录严格一致），两个分组计数为 0，并附安全说明 `per_turn_unavailable: ...`。取消或部分记录不会被写成 0 毫秒。真实运行请使用 `--measurement real` 并保留原始 `streaming_metrics.json`。
