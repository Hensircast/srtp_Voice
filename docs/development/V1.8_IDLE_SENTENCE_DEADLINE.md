# V1.8：模型停词时的分句等待上限

10/05 修正：自然模式以前阻塞等待下一个 token，只有下一次 `feed` 才能检查分句截止。现在使用容量4的 token 桥，主消费线程每5–50ms有界等待一次，在空闲期调用原 `flush_due`。已经够长的完整分句可先进入既有 TTS，不增加模型请求，不调整 VAD 或声线。

`STREAM_NATURAL_BOUNDARIES=1`仍为默认；`0`保留原同步迭代/关闭和旧分句策略，可回退新路径。`STREAM_SENTENCE_MAX_WAIT_SECONDS`默认仍0.8秒，是**文本缓冲开始后**的分句等待参数，不是“用户说完到开口”全链路保证。低于最小字数的残片、小数/缩写尚无明确后续、TTS背压和资源调度都可能让实际播放更晚；不要为赶快把默认字数或VAD静音阈值盲目调小。

## 验证和限制

- DeepSeek主执行桥及自有回归；Codex独立门控测试复现原4失败，并审查/修正启动异常的原子关闭所有权。主线程仍单独操作chunker、事件、序号和完整文字重建，不让定时线程并发改文本。硬边界预览只播一次，最终诊断在待播文字入队之后发布。
- 自然取消只做0.1秒有界读线程等待，不跨线程关闭正在执行的源。若HTTP读取正阻塞，源由原读线程在既有读超时后关闭；daemon只是进程退出兜底，不能宣称所有线程立即退出。旧模式不创建后台读线程。
- 所有门控源、WAV和播放回调均为离线替身，证明“模型仍停词时已经启动合成/假播放”和生命周期边界，不能冒充真实模型、扬声器或老人儿童听感测试。默认完整、精确提交CI和最新Review状态见WORK_CHECKPOINT及本轮run.md。
- 本轮不替换模型、不下载、不修改用户`.env`或全局设置。Piper音色平淡仍需真实试听，不将此修复说成更换了拟人声线。

## 下一轮 PowerShell 真机复测

在项目根目录的新测试终端运行，使用耳机和相同公开问题，连续6–10轮；首轮单列。确认原Ollama与既有模型正常，自检失败先核实原因，不因此重装/换模型。

```powershell
.\venv\Scripts\python.exe -m tools.workbench doctor --online
if ($LASTEXITCODE -ne 0) { throw '先处理自检警告或错误' }
$env:STREAM_NATURAL_BOUNDARIES = '1'
$env:STREAM_SENTENCE_MAX_WAIT_SECONDS = '0.8'
# 本轮固定保持原预览；若上一组为0，则用0保持可比，不同时改变两个因素。
$env:STREAM_ASR_PARTIALS_ENABLED = '1'
$runName = 'idle-deadline-' + (Get-Date -Format 'yyyyMMdd-HHmmss') + '-' + ([Guid]::NewGuid().ToString('N').Substring(0,8))
$env:OUTPUT_DIR = "outputs/$runName"
$env:MEMORY_FILE = "$env:OUTPUT_DIR/memory.json"
$env:STATE_FILE = "$env:OUTPUT_DIR/emotion_state.json"
.\venv\Scripts\python.exe -m tools.workbench snapshot --output "$env:OUTPUT_DIR/recording-context.json" --label $runName
if ($LASTEXITCODE -ne 0) { throw '快照失败，未开始复测' }
.\venv\Scripts\python.exe main.py --mode vad --streaming --continuous
# 6–10轮后Ctrl+C，再在同一终端运行：
.\venv\Scripts\python.exe -m tools.workbench baseline --metrics "$env:OUTPUT_DIR/streaming_metrics.json" --recording-metadata "$env:OUTPUT_DIR/recording-context.json" --output "$env:OUTPUT_DIR/timing-baseline.json" --measurement real --label $runName
if ($LASTEXITCODE -ne 0) { throw '基线导出失败，请保留原结果' }
$m = Get-Content -Raw -Encoding UTF8 "$env:OUTPUT_DIR/streaming_metrics.json" | ConvertFrom-Json
$m.summary | ConvertTo-Json -Depth 6
```

重点看`first_sentence_ms`与`endpoint_to_playback_ms`，并核对完整识别/回答、句中是否有无意义碎片、播放是否重复或有长空档。另按V1.8_HTTP_DIAGNOSTICS.md核对服务加载/输入处理，不拿前两轮慢直接判断为冷启动。可分享脱敏`timing-baseline.json`，不上传录音、事件文字或记忆；没有同配置旧真机结果时明确缺基线，不能凭模拟数据承诺提升百分比。

若要使用`STREAM_NATURAL_BOUNDARIES=0`回退，另建新输出/记忆并重新快照。两种策略不同，结果不是严格同配置的纯代码A/B；不得改快照或指纹强行让比较工具通过。进一步预览开关对照见V1.8_ASR_PREVIEW_POLICY.md。
