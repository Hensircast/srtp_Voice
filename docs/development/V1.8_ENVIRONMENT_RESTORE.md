## UTF-8 独立性验证

代码路径使用显式编码：

- Ollama NDJSON 使用 UTF-8 增量解码器处理跨字节中文分片。
- JSON 文件统一以 UTF-8 读写并保留中文。
- Piper 文本输入显式编码为 UTF-8，错误输出以 UTF-8 容错解码。
- PowerShell 验收命令显式使用 `Get-Content -Encoding UTF8`。

在独立 PowerShell 进程中移除 `PYTHONUTF8` 和 `PYTHONIOENCODING` 后执行：

```powershell
Remove-Item Env:PYTHONUTF8 -ErrorAction SilentlyContinue
Remove-Item Env:PYTHONIOENCODING -ErrorAction SilentlyContinue
.\venv\Scripts\python.exe -m pytest -q -p no:cacheprovider --basetemp outputs\pytest-v18-final-no-global-utf8
```

结果：372 项通过。随后对 Ollama NDJSON、中文句子切分、ASR、SER、Piper、JSON、流式运行时和同步连续模式执行定向测试，162 项通过。

## 恢复结论

- 没有满足“本阶段持久新增且需要删除”条件的 Windows User 或 Machine 变量，因此没有执行系统环境写操作。
- 没有变量需要管理员权限、注册表写入或 Machine 级修改。
- 没有修改 `PATH`、凭证、Ollama 服务配置、模型、录音或个人文件。
- V1.8 不依赖全局 `PYTHONUTF8` 或 `PYTHONIOENCODING`。
- 不要求重启 VS Code 或 Windows；若旧 PowerShell 仍保留手册中的临时变量，关闭该终端即可自然恢复。
