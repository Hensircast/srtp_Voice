## 已知风险与待实测项

- 单调时间只用于耗时计算，不可解释为真实日期时间。
- faster-whisper partial 使用增长 PCM 快照而不是原生增量解码器状态。
- 流式文本与 action 分离；流式 action 使用确定性默认值，同步结构化策略路径继续保留。
- 最大等待切分在新 token、显式轮询或流结束时检查；底层 HTTP 无字节期间受 LLM timeout 约束。
- 真实 Ollama 与 Piper 的 `--no-play` 路径已复验；麦克风、实际音频播放、主观首响延迟和回声回采仍需按验收手册实测。
- 无回声消除时应优先使用耳机，避免扬声器声音被麦克风重新识别。
