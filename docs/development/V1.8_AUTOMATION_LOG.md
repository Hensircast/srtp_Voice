## 已知风险与待实测项

- 当前阶段只提供事件与计时基础，尚未接入 LLM、TTS、ASR 的实际流式链路。
- 单调时间只用于耗时计算，不可解释为真实日期时间。
- 真实麦克风、真实 Piper、音频播放、主观首响延迟和回声回采需在自动阶段完成后实测。
- 无回声消除时应优先使用耳机，避免扬声器声音被麦克风重新识别。

## 外部阻塞恢复步骤

1. 确认仍位于 `v1.8-streaming-low-latency`，且未切换到受保护分支。
2. 运行 `git status -sb`，识别并保留所有用户修改。

4. 使用 `gh auth status` 检查认证；只在认证有效后继续 PR、CI 和 Review 操作。
5. 若 GitHub Actions 是平台启动故障，只重试一次并记录 run URL、时间和 request ID，不修改业务代码。
